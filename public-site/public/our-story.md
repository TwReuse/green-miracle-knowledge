# 從過去走向未來：服務如何持續演進

綠色奇蹟二十多年的回收、整修、災後支援與跨組織合作，持續回答同一個問題：如何把社會的善意，轉化為能持續運作、被檢查、被改善，也能交給下一代的服務。

## 服務起點 { #history }

二十年前，電腦與網路快速進入家庭、學校與工作現場。但資訊設備並沒有平均抵達每個地方：一端是企業與家庭持續汰換仍可使用的電腦，另一端則有人缺少基本的數位工具。

2004 年，矽聯科技股份有限公司年度董事會與同仁共同訂定社會回饋服務計畫，投入人力建立電腦回收、整修與轉捐贈服務，並希望透過網路讓更多人參與。綠色奇蹟服務從這裡誕生。

2004 年成立的是「綠色奇蹟服務計畫」；協會法人於 2021 年成立。早期的綠色奇蹟主要是一個網站與服務名稱，背後由公司同仁、整修人員、物流與合作夥伴共同摸索：怎麼找到願意捐出設備的人？怎麼判斷電腦能否繼續使用？又怎麼讓真正有需要的人提出申請？

### 把善意變成可以運作的流程 { #service-process }

服務不是一次完成的。2005 年，團隊透過微軟線上平台取得再生電腦公益授權相關資格；2006 年完成線上填單與物流回收；2007 年開始接收再生電腦線上申請；2008 年再利用當時流行的論壇與社群方式宣傳回收。

每一次改變都回應一個具體瓶頸。2005 年申請增加，但合作回收商受派車數量門檻限制，回收設備也有缺件與品質問題；2006 年因此開始試作免費物流到府回收，建立一台也能提出申請的消費者回收服務。2008 年城市電子垃圾流向偏鄉的新聞引發討論後，團隊進一步要求整修夥伴提高檢測與交付規格，並為綠色奇蹟出廠的再生電腦提供六個月免費保固。

這些看似是網站功能，實際解決的是公益服務最困難的幾個問題：設備從哪裡來、需求如何被看見、物流如何銜接、軟體如何合法使用，以及每一部電腦能否被追蹤。

服務規模從真實場域的小規模嘗試開始，再把有效的方法整理成 SOP（標準作業流程）：

1. 先確認服務對象真正遇到的問題，再決定設備與服務方式。
2. 由綠色奇蹟、公益團體、學校、企業、社群與青年分工，說清楚誰負責需求、設備、陪伴、例外與追蹤。
3. 保留檢測、授權、交付、使用與回訪需要的最少紀錄，讓結果可以被檢查。
4. 專案結束後回看哪些做法有效、哪些造成負擔，再形成檢核表、教材或夥伴交接方式。
5. 當方法能由不同夥伴穩定執行，再依實際成果擴大服務。

公益共創是服務演進的方法。綠色奇蹟提供設備判斷、整修、授權與媒合能力；公益團體與學校理解現場並陪伴使用；企業及社群提供設備、資金或專業；青年則可以參與需求訪談、數位教學、環境研究、成果驗證與改善提案。再生的目的，是讓每一份資源在適合的位置真正發揮效益。

### 災後支援帶來新的連結

八八風災後，綠色奇蹟支援南部多所學校與課輔單位的電腦教室復原。從屏東、高雄、台南到台東，至次年截止完成 10 多個單位、200 餘部電腦的捐贈。早期逐校明細目前缺少完整紀錄，因此「10 多個單位、200 餘部電腦」保留為當時核定的歷史彙總。

同一時期，高雄啟禾扶輪社也在不同學校投入災後服務。雙方當時各自執行災後服務，在分享中發現彼此都關心相近的問題，因而相識。後來，經費、企業設備、需求轉介、訪視、交付與成果分享逐步形成長期合作；綠色奇蹟與啟禾始終是彼此獨立的組織。

### 從企業公益服務走向獨立法人

隨著服務擴大，回收、整修與捐贈逐步形成需要穩定制度、公開責任與長期治理的服務。團隊在 2020 年啟動協會籌組，2021 年成立社團法人綠色奇蹟公益服務網協會，由獨立 NPO 法人承接治理。

矽聯科技仍可提供技術與代管支持，但協會的會務、財務、個資、品牌與公開決策，必須由協會自己的治理機制負責。

2021 年也加強回收電腦的個資與儲存裝置治理：再生電腦改用新品 SSD；舊硬碟依當時作業完成低階格式化後，品質尚可者作為儲存碟或維修備品，不符合再利用規範者破壞、造冊並報廢。這項歷史政策把捐贈者資料保護、受贈設備可靠度、備品利用與報廢責任放進同一套分流考量。

## 年度改善 { #present }

走過二十年，設備條件與服務方法持續隨環境調整。年度觀察的作用，是記錄外部環境如何改變、服務受到什麼影響、綠色奇蹟如何回應，以及下一年還要驗證什麼。今天的「現在」也會成為明天的歷史，因此每一年的判斷都要保留時間、來源與限制。

### 2026 年：規格與成本同時改變

Windows 10 已於 2025 年 10 月 14 日結束一般支援；Windows 11 對處理器、UEFI／Secure Boot 與 TPM 2.0 等條件的要求，也讓部分過去能使用的舊機不再適合繼續以 Windows 電腦交付。AI 與資料中心需求同時使記憶體及 SSD 供應與價格承壓，安全可用設備的門檻因而提高。

協會 2026 年 6 月特定批次的 SSD 與記憶體報價顯示，同一筆經費能完成的升級組數下降，而且尚未包含檢測、資料清除、合法授權、物流、保固、數位教育與後續陪伴成本。這份資料的適用範圍，是協會該月特定規格與採購條件的批次報價；完整品項、試算及成交狀態集中保留在年度觀察頁。

綠色奇蹟提高可交付規格、重新分流舊機、募集從「收到」到「安全可用」之間的成本，並嘗試把防詐、網路霸凌、網路成癮警訊及帳號安全教育納入交付與回訪。

## 世代傳承 { #future }

從桌上型電腦與網路普及，到行動裝置、遠距學習，再到今天的 AI 世代，數位工具一直在變。持續面對的核心問題，是資源如何被公平取得，以及一項服務能否長期被信任。

綠色奇蹟累積的不只是整修電腦的技術，而是把資訊流、物流、整修、合法授權、需求媒合、交付與後續服務連成一條可持續改善的路。這些經驗將成為面對下一種數位落差與循環問題的基礎。

未來會持續面對四類問題：AI 與新工具是否擴大數位落差、家庭是否具備安全使用網路的能力、氣候變化與循環使用如何連結，以及公益夥伴的資源能否被更有效地組合。青年將進入真實場域，透過研究、論壇、服務與反思，與不同世代共同提出可以驗證的方案。

2024 年，綠色奇蹟與啟禾扶輪社支持左營高中扶少團參與沖繩 SDGs 青年論壇，討論氣候、減碳與再生電腦。這筆[官網活動紀錄](https://www.reuse.org.tw/eventdetail.html?actid=69B6D21E-F806-49A8-9708-B950EC4E71AA)呈現一次可核對的青年參與經驗，適用範圍為該次活動；青年年度論壇仍屬後續可發展方向。

未來的服務會沿著同一個循環前進：看見新的問題、小規模嘗試、留下證據、整理成 SOP、交給更多夥伴實作，再由下一次年度觀察檢查是否真的擴大影響。這就是「服務傳承」與「永續共創」彼此連在一起的方式。
