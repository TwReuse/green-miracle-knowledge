# 片段資料收納原則

## 來源分流

- Notion：志工日常記事、QA、訪談與文章素材；保留在權限控管空間，Repo 只收核定摘要。
- 官網／Blogger：保存公開網址、發布時間、版本、事件 ID 與可支持的主張，不複製整篇第三方內容。
- 行政回報：每個數字附期間、母體、狀態、去重、產生人與更正紀錄。
- 後台資料庫：只使用去識別、只讀、版本化出口；不得讓公開 AI 直接連正式資料庫。

## 最小安全 Gate

1. 判定 `privacy_class` 與 `rights_status` 後才整理內容。
2. 個人與兒少資訊不公開；學校、課輔或照護單位可依核定公開範圍使用。
3. 合作單位名稱可描述歷史合作，但 Logo、照片、影音與引言另做權利檢查。
4. 同一事件跨系統重複時先建立共同事件 ID，不直接相加。
5. 片段只能支持其實際內容；背景新聞未指名綠色奇蹟時只作背景。
6. 經頁面審核後仍須由 Chinwen 最終核定。
