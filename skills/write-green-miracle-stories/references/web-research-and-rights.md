# 網路研究與權利規範

## 綠色奇蹟核定素材規則

- 十年以上歷史影音可只保存連結、標題與基本事件軌跡，不強制逐秒時間碼。
- 第三方新聞影片可連結；截圖要公開重製前仍確認著作權與使用情境。
- 理事長與理事的組織職務發言不另逐人取同意，但仍核對姓名、角色、日期、事件與核定版本。
- 學校、課輔與照護單位名稱可公開；個人、家庭處境與兒少資料須去識別且不公開。
- 過往合作可引用單位名稱；現有合作使用 Logo 時，取得合作方正式檔案與使用規範。

## 搜尋流程

1. 先寫出要補的主張，不做無邊界蒐集。
2. 建立查詢矩陣：`綠色奇蹟`、`再生電腦`＋年份／人物／縣市／學校／合作方／災害／服務。
3. 優先找原始發布者，再找新聞及轉載；使用 `site:gov.tw`、`site:edu.tw`、`site:org.tw`、`site:youtube.com` 協助定位。
4. 開啟原頁確認內容，不以搜尋結果摘要作證。
5. 分開記錄發布日期與事件日期；影片加記頻道、講者及時間碼。
6. 對重大日期、合作、人物引言及成果數字進行交叉驗證。
7. 將候選填入來源卡，標示採用、僅背景、拒用或待核定。

- `"綠色奇蹟" 邱勤文`
- `"綠色奇蹟" 八八風災`
- `"綠色奇蹟" 華碩 希望工程`
- `"綠色奇蹟" site:edu.tw`
- `"綠色奇蹟" site:youtube.com`
- `再生電腦 數位落差 台灣 <年份>`

依研究缺口替換名稱、年份與地點，不把範例視為完整清單。

## 著作權與素材邊界

- 公開 Repo 保存來源中繼資料、摘要、短引文與連結，不保存未授權全文、完整逐字稿或影片副本。
- 短引文標示發布者與連結；影音引文附時間碼。引用篇幅應限於支持分析所需。
- YouTube 或新聞影片原則上提供連結；嵌入、下載、剪輯及重製須另查平台條款與權利人授權。
- 照片、Logo、報導截圖、音樂、人物肖像及兒少素材分別檢查，不因網頁公開即可自由使用。
- 權利不明時設為 `permission-required`，不得進入公開成品。
- 頁面失效時保留原網址與查閱日期；網頁存檔只作查證線索，仍須遵守原內容權利。

## 個資與敏感內容

不公開住址、電話、電子郵件、受贈者清冊、設備可識別資料、兒少姓名或未授權健康／家庭資訊。案例故事優先使用已授權內容；匿名化不得造成虛構或誤導。

## 來源卡最低欄位

記錄標題、媒體類型、發布者、作者／頻道、發布日期、事件日期、URL、查閱日期、支持主張、主張狀態、故事用途、權利狀態及個資風險。影片另記時間碼與發言者。
