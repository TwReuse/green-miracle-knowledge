# 台灣數位背景資料指引

## 可研究主題

- 家戶與企業電腦、寬頻及網際網路普及。
- 城鄉、年齡、教育及所得造成的數位落差。
- 校園資訊教育與偏鄉設備需求。
- 電子廢棄物、資源回收與循環經濟政策。
- 正版軟體、再生電腦授權與資訊安全環境。
- 八八風災等重大事件後的校園與社區重建。

## 來源偏好

優先使用行政院、數位發展部及其前身機關、主計總處、教育部、環境部及其前身機關、國家發展委員會、學術研究與事件同期機構資料。媒體專題可補社會觀察，但統計數字應回到原始報告。

## 使用限制

- 明確寫出資料年度、調查母體、指標定義與發布機關。
- 全國統計不得直接推定某所學校、某個家庭或受贈者的處境。
- 今日的「循環經濟」「ESG」「數位平權」語彙可以解釋歷史意義，但不得假裝 2004 年參與者當時已使用相同概念。
- 背景資料只建立時代脈絡；綠色奇蹟事件仍需自己的來源。
