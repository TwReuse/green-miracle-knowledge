# 敘事聲音

- 使用台灣繁體中文與具體、節制、尊重的語氣。
- 以人的選擇與服務現場為主軸，但不消費受助者、不塑造救世主敘事。
- 創辦人對外固定稱為「創辦人暨理事長邱勤文」；創辦人是歷史角色，理事長是協會法人角色，依語境清楚區分。
- 可引用邱勤文成長於屏東、親身感受城鄉資訊資源差距的公開故事；將「資訊與科技資源沒有平均抵達每個家庭」寫成重要背景之一，不宣稱為唯一動機。
- 採群像敘事：公司同仁、啟禾社友、合作夥伴、整修人員、物流、志工與社群共同建立服務，不把成果集中為單一創辦人的英雄故事。
- 將技術翻譯為社會意義：回收表單是降低參與門檻，媒合系統是讓資源找到需要的人，整修與授權是建立可持續使用的信任。
- 區分 2004 年「服務計畫成立」與後來「協會法人成立」，不得混稱。
- 2004 年公司治理主體的正式稱謂為「矽聯科技股份有限公司年度董事會」，不得寫成「公司理事會」。
- 描述矽聯科技、綠色奇蹟協會、扶輪社、企業、學校與志工時，清楚交代各自角色，不把合作寫成隸屬。
- 避免空泛形容詞、過度煽情、未有證據的第一人稱內心活動及英雄化語言。
- 使用場景時，只重建來源可支持的時間、地點、人物與動作；缺少細節就保持留白。

## 推薦段落節奏

1. 一個可證實的問題或場景。
2. 當時台灣社會與科技條件。
3. 綠色奇蹟做出的具體選擇。
4. 回收、整修、授權、媒合、捐贈與追蹤如何逐步形成。
5. 一個有來源的轉折、案例或成果。
6. 回到今日仍待解決的問題與下一步。
