# 綠色奇蹟公開知識庫

## 這個網站解決什麼問題

本知識庫讓綠色奇蹟團隊、志工、合作夥伴、媒體及社會大眾，從同一個經核定的來源理解協會的身分、使命、服務、成果及參與方式。

本頁與標示為 `approved` 的內容，已納入公開知識基線；其他狀態的頁面仍只可作為審查、補證或規劃材料。

## 依讀者開始

| 讀者 | 建議入口 | 可以完成什麼 |
|---|---|---|
| 社會大眾與媒體 | 認識綠色奇蹟、服務與影響 | 取得一致且可追溯的公開介紹 |
| 設備捐贈者與企業 | 服務閉環、參與方式 | 理解設備如何被處理與形成公益價值 |
| 受贈申請者 | 服務閉環 | 理解申請、審核、交付與例外；現行條件仍待核定 |
| 新進成員與志工 | 教育訓練 | 了解 NPO 身分、服務原則，並從二十年案例學習解決未來問題 |
| 內容編輯與發布者 | 治理與透明 | 依來源、核定與公開邊界維護內容 |
| 客服、網站與 AI | AI 知識卡 | 使用有狀態、限制、來源與轉接條件的短答案，不從草案過度承諾 |

- [Notion 治理、章程、勸募與作業資料盤點](governance/notion-governance-inventory.md)：分辨現行、內部、審核中、草案與歷史文件。

## 這裡不是什麼

- 不是受贈者、捐贈者或志工個資資料庫。
- 不是內部財務、會務、合約或設備追蹤系統。
- 不是未核定宣稱的暫存區。
- 不是矽聯科技公司治理文件的延伸站。

## 完成標誌

當一項知識同時具備來源、核定角色、公開狀態、審視期限及可使用範圍，才算能被官網、簡報、行銷與 AI 可靠引用。
