# 如何核定成果與影響力數字

## 結論

200 台以上、400 台以上、500 台以上、數千台、單台減碳公斤數等既有宣稱，目前不能直接視為公開 SSOT（單一真實來源）。每個數字都要補齊期間、定義、資料來源、去重方式、核定人與更正紀錄。

## 建議指標層級

| 層級 | 例子 | 注意事項 |
|---|---|---|
| 投入 | 設備、經費、志工時數 | 不等於已完成成果 |
| 產出 | 合格整修台數、交付台數 | 要定義退貨、重送及同設備跨年度去重 |
| 結果 | 受贈後持續使用、學習或服務改善 | 需要追蹤方法及同意 |
| 長期影響 | 數位平權、環境效益 | 需建立因果邊界及方法論，不得由台數直接推定 |

## 減碳邊界

若對外發布環境效益，至少要說明設備分類、延長使用年限、替代情境、生命週期範圍、資料來源、係數版本與不確定性。
