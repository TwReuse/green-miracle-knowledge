# 矽聯科技時期的再生電腦史料

## 先說結論

獨立法人成立以前，新聞、校方與公開資料經常直接使用「矽聯科技」，或將綠色奇蹟描述為矽聯科技建立、支持或規劃經營的網站與公益平台。因此，早期史料不能只搜尋「綠色奇蹟」，也要以矽聯科技、邱勤文、再生電腦、二手電腦、愛心電腦及合作單位交叉查找。

這些來源支持一條清楚的歷史主線：早期執行與合作主體主要是矽聯科技，「綠色奇蹟」是網站與服務名稱；整修廠、物流、學校、企業及公益團體依專案分工參與。服務多年演進後，才於 2021 年進入獨立法人治理。

## 來源差異

2008 年逢甲大學報導稱矽聯科技於「去年底」成立綠色奇蹟網站；Chinwen 已核定 2004 年綠色奇蹟服務計畫成立，並透過網路推動服務。這可能是網站版本、改版、正式對外啟用或媒體概括差異，目前尚無足夠證據判定。

治理處理如下：

- 2004 年正式寫「綠色奇蹟服務計畫成立／服務誕生」，同時明確說明不是協會法人成立。
- 2008 報導如實登錄，但不將「去年底」當作唯一建站年份。
- 待取得網域、網站備份、部署紀錄或 Wayback 快照，再建立網站版本時間線。

## 維運規則

- 搜尋時同時使用公司名、網站名、人物、專案名、學校、地區與合作單位。
- 搜尋摘要只作線索，開啟原始頁面核對後才能列為公開紀錄。
- 早期報導中的「成立」必須區分網站、服務、平台與法人。
- 公開可讀不等於可重製；圖片、影片、全文及兒少素材仍須完成權利檢查。
