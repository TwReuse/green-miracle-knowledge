# 如何把知識發布到網站、行銷與簡報

## 發布前檢查

1. 只選用 `approved` 且 `public: true` 的內容。
2. 記錄知識 ID、版本、來源及核定角色。
3. 數字保留期間、單位、定義與必要方法說明。
4. 圖片、Logo 與引言確認載體、期間及共同品牌限制。
5. 連結至最新申請、捐贈或聯絡入口。
6. 發布後登錄載體網址，以便來源更正時同步處理。

## 例外

- 緊急活動資訊仍須由授權發布人確認。
- 如果來源被撤回、權利到期或事實變更，先下架再補正。
- 翻譯、摘要與 AI 重組都不能改變核定口徑。
