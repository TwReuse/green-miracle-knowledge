# 新成員如何正確介紹綠色奇蹟

## 必須先知道

- 綠色奇蹟是獨立法人，不是矽聯科技的部門或產品。
- 歷史淵源可以說明，但現行治理、資料及公開決策屬於協會。
- 未在公開知識庫核定的數字、合作名稱、募款說法與照片不得自行使用。
- 不把受贈者困境當成行銷素材；案例使用應尊重當事人、取得授權並避免不必要識別。

## 遇到不知道的問題

不要推測。記錄提問、查找知識 ID；找不到或頁面為 `review`／`blocked` 時，交由知識治理或方案負責人確認。
