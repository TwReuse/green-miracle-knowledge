# 教育訓練入口

教育訓練的目的不是背誦組織沿革，而是把歷史案例轉化為可重用的能力、資源判斷與改善方法。

## 訓練對象

- 新進工作人員與志工。
- 董監事與方案負責人。
- 內容編輯、社群、簡報及媒體聯絡人。
- 設備、物流、整修及合作夥伴窗口。

## 最小課程

1. 綠色奇蹟的獨立法人定位與歷史。
2. 再生電腦服務閉環與角色交接。
3. 個資、兒少、肖像、設備資料與公開邊界。
4. 如何核對成果數字、合作關係與來源。
5. 如何提出、審查及發布公開內容。
6. 發現錯誤、權利撤回或服務異動時如何更正。
7. 從二十年案例拆出能力與資源，提出下一個可驗證的改善題目。

## 訓練完成標誌

受訓者能分辨「可公開、待核定、禁止公開」，能找到權威來源，並知道遇到例外時應交給哪一個角色處理。
