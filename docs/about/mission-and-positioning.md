# 綠色奇蹟的使命與服務定位

## 定位草案

綠色奇蹟以環保回收與數位公益為核心，將可再利用的舊電腦整修、依法處理軟體與資料安全，再媒合給有需要的人與組織。

## 核心價值草案

- 延長設備生命，減少可用資源被浪費。
- 讓數位工具回到學習、工作及公益服務現場。
- 以可追蹤的跨組織合作建立信任。
- 兼顧設備品質、資料安全、軟體合法性與後續支持。

以上文字尚待協會核定，不是正式使命或募款文案。
