# 歷史資料核定工作表

## 核定原則

公開內容以法人／政府文件、事件同期的合作方資料、協會正式成果報告為優先。2018 年後的營運成果，以官網資料庫及公開紀錄作為主要追溯來源，重大數字仍須附期間、狀態、統計定義與去重方式。2018 年以前不再全面補齊 Excel、紙本或舊系統明細；歷程可由新聞、政府、合作方公開資料及 Owner 核定脈絡支持。Notion 草稿只作為查證線索。

## 後續資料工作優先序

1. 建立 2018 年後官網成果的狀態字典、統計定義、去重方式與更正紀錄。
2. 規劃新版官網可供 Repo 使用的去識別、版本化公開資料出口。
3. 以新聞、政府、合作方與協會公開資料補充代表性歷程，不追求 2004–2017 逐筆明細完整度。
4. 成立大會、法人登記、章程及歷屆理監事等法定治理文件，依公開與保存責任持續維護。
5. 慈濟、扶輪、學校與企業合作成果仍分體系呈現，不直接加總。

完整政策與未來需求候選見[官網資料如何成為可信任來源並供 AI 引用](../governance/website-data-provenance.md)。
