# 從這裡認識綠色奇蹟

一部被汰換的電腦，可能只是企業倉庫裡等待處理的設備；經過回收、檢測、整修、合法授權與需求媒合後，也可能重新成為孩子學習、家庭工作或公益組織服務的工具。

綠色奇蹟從 2004 年的企業社會回饋服務計畫出發，逐步建立線上回收、再生電腦申請、物流、整修、捐贈與後續服務。2021 年起，由社團法人綠色奇蹟公益服務網協會承接獨立法人治理。
