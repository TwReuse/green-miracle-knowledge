# 詞彙表

| 名稱 | 定義 |
|---|---|
| NPO（非營利組織） | 以公益目的運作，不以分配盈餘給成員為目的的組織概念；實際法人地位仍以登記為準。 |
| SSOT（單一真實來源） | 對特定範圍提供唯一核定版本及追溯入口。 |
| 公開知識 | 已核定可供社會大眾、媒體、合作夥伴及公開應用引用的資訊。 |
| 來源證據 | 能支持一項事實、數字、權利或決策的可核對紀錄。 |
| 去識別 | 降低資料指向特定個人的可能性；仍須評估是否能與其他資訊重新識別。 |
| 核定 | 由具有相應法人或受授權權限的角色確認內容及適用範圍。 |
