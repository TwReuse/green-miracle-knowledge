# 矽聯代管如何與協會法人權責分開

## 核定結論

本知識 Repo 使用 `TwReuse/green-miracle-knowledge`，目前由矽聯科技提供 GitHub 組織與技術代管，Repo 管理人為 Chinwen。綠色奇蹟公益服務網協會仍是公開知識 SSOT（單一真實來源）的法人內容權責主體。

## 權責矩陣

| 項目 | 綠色奇蹟 | 矽聯科技／TwReuse | Chinwen |
|---|---|---|---|
| 法人身分、使命與政策 | 核定 | 不代為決定 | 依協會權限管理知識 |
| GitHub Repo、CI 與 Pages | 提出內容需求 | 提供技術代管 | 管理設定與發布 |
| 募款、財務及法定公告 | 依章程核定 | 不代為核定 | 依正式授權執行 |
| 個資、肖像與案例權利 | 保存同意及決策 | 協助技術保護 | 確認審查完成後發布 |
| 成果與影響力數字 | 核定定義與數據 | 可提供工具支援 | 管理版本與追溯 |
| 網站、簡報、行銷及 AI 引用 | 決定可公開內容 | 提供整合技術 | 控制 SSOT 發布版本 |

## 邊界條件

- `TwReuse` 組織擁有 GitHub 層級的技術控制，不等於矽聯取得協會內容著作權或法人決策權。
- Chinwen 同時具創辦人、管理人或矽聯角色時，仍應在高風險內容標明是以哪一個授權身分核定。
- 公開 Repo 發生資安、帳號或 CI 問題，由技術代管方處理；事實錯誤、權利撤回或法人政策變更，由協會決定內容處置。

## 維運與備援

1. 啟用 `main` 分支保護、PR（合併請求）、`docs-check` 及禁止強制推送。
2. Chinwen 為主要管理人；另指定至少一位備援管理人，避免單一帳號風險。
3. GitHub 帳號使用多因素驗證，不在 Repo 保存密碼、權杖或金鑰。
4. 每年至少一次確認代管關係、管理人、網域、權限與備份。
5. 若未來移轉至協會自有 GitHub 組織，保留 Repo 名稱、Git 歷史、Issue、Release、知識 ID 與重新導向。

## 例外處理

- **Chinwen 帳號無法使用**：由備援管理人及 `TwReuse` 組織管理者依核定紀錄恢復存取。
- **需要緊急下架**：先由技術管理人停止 Pages 或撤回公開內容，再補齊協會核定及更正紀錄。
- **雙方對內容有歧見**：法人內容以協會正式決議為準；技術安全限制由矽聯提出風險與替代方案。

## 完成標誌

遠端 Repo 已建立、Chinwen 帳號已核對、分支保護與 CI 已啟用、備援管理人已指定，且 README 與公開站均能看到本代管聲明。
