# 誰可以核定哪些公開知識

## 決策關鍵

創辦人身分、公司職務與協會法人權限要分開判斷。目前經營管理與本知識庫之一般內容、方案、資料、隱私及發布決策由 Chinwen 統籌核定；法定應由會員大會、理事會、監事會或主管機關處理的事項，仍依章程與法令辦理。

| 角色 | 主要責任 | 不可單獨決定 |
|---|---|---|
| 法人治理機關 | 依章程處理重大政策、品牌、法定權責與高風險公開事項 | 日常編修可授權執行 |
| Chinwen／知識治理負責人 | 架構、一般文字、版本、審視、方案、資料與發布協調 | 不得取代法定決議或第三方授權 |
| Chinwen／資料證據負責人 | 數字定義、來源、去重及更正 | 不得把推論寫成正式成果 |
| Chinwen／權利與隱私審查人 | 個資、肖像、兒少及素材授權檢查 | 不得替外部權利人授權 |
| TwReuse 組織管理者 | 帳號失效時執行 Repo 存取與技術復原 | 不取得協會內容核定權 |

## 例外

協會規模尚小，同一人可以兼任多個角色。目前由 Chinwen 統籌核定，不強制指定第二位內容覆核人；但仍須保留來源、版本、PR、核定證據與審視日期。法令、章程或第三方授權要求其他人同意時，不適用此例外。
