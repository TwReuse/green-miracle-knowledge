# 誰可以核定哪些公開知識

## 決策關鍵

創辦人身分、公司職務與協會法人權限要分開判斷。邱勤文可受協會授權擔任知識治理負責人，但正式權限範圍應留有協會決議或授權紀錄。

| 角色 | 主要責任 | 不可單獨決定 |
|---|---|---|
| 法人治理機關 | 重大政策、品牌、授權與高風險公開事項 | 逐頁日常編修可正式授權 |
| 知識治理負責人 | 架構、一般文字、版本、審視與發布協調 | 法定公告、財務、個資及第三方權利 |
| 方案負責人 | 服務現況、資格、例外與教育內容 | 超出方案權限的法人承諾 |
| 資料證據負責人 | 數字定義、來源、去重及更正 | 未經授權的影響力推論 |
| 權利與隱私審查人 | 個資、肖像、兒少及素材授權 | 服務與財務政策 |
| 發布維護人 | 依核定結果合併與發布 | 自行變更核定口徑 |

## 例外

如協會規模尚小，同一人可以兼任多個角色，但高風險內容至少要有第二人覆核，並留下核定紀錄。
